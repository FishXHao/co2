## 2. 網站地圖

> **Assumption**：層級與節點依 SOW 服務類型假設，須以 P0 勘查結果調整。

```
首頁 (/)
├── 服務列表 (/services)
│   └── 服務詳細 (/services/:id)
│       └── [核心服務表單] (/apply/:serviceId)  ← C
│           └── [提交結果] (/apply/:serviceId/result)  ← C
├── 公開內容頁 (/info/:slug)  ← 多個靜態頁面
├── [登入] (/login)  ← C
│   └── [登入後首頁 / 個人頁] (/account)  ← C
├── 404 (/* catch-all)
├── 403 (/403)
└── 500 (/500)
```

### 2.1 頁面層級說明

| 層級 | 說明 | 範例 |
|------|------|------|
| L0 | 根入口 | 首頁 `/` |
| L1 | 主要功能區塊 | 服務列表、公開內容、登入 |
| L2 | 詳細頁或操作頁 | 服務詳細、申辦表單 |
| L3 | 結果頁 | 提交結果頁 |
| SYS | 系統頁面 | 404、403、500 |

## 3. 導航與麵包屑

### 3.1 主導航（Header）

> **Assumption**：導航項目依服務類型假設，品牌名稱、Logo 及服務項目名稱待需求方確認。

| 項目 | 路由 | 顯示對象 | 說明 |
|------|------|---------|------|
| 首頁 Logo/名稱 | `/` | 所有使用者 | 點擊返回首頁 |
| 服務項目 | `/services` | 所有使用者 | 主要服務入口 |
| 公開資訊 | `/info/...` | 所有使用者 | 靜態內容（待確認項目名稱） |
| 登入 | `/login` | 未登入使用者 | Assumption：需登入才顯示 |
| 我的帳戶 | `/account` | 已登入使用者 | Assumption：登入後顯示 |
| 登出 | `/logout` | 已登入使用者 | Assumption：登入後顯示 |

**響應式行為**：
- 桌面（≥ 1024px）：橫向導航列
- 平板（768–1023px）：導航列可縮排或加入漢堡選單
- 手機（< 768px）：漢堡選單，點擊展開垂直列表

> **Assumption**：行動版導航形式及圖示待視覺設計核准。

### 3.2 頁尾（Footer）

> **Assumption**：頁尾內容（著作權、聯絡資訊、相關連結）待需求方提供。

建議包含：
- 著作權聲明（年份 + 機構名稱，待確認）
- 相關政策連結（隱私政策、使用條款，待確認是否需要）
- 聯絡資訊（待確認）

### 3.3 麵包屑

| 頁面 | 麵包屑路徑 |
|------|-----------|
| 服務列表 | 首頁 > 服務項目 |
| 服務詳細 | 首頁 > 服務項目 > `[服務名稱]` |
| 申辦表單 | 首頁 > 服務項目 > `[服務名稱]` > 申辦 |
| 提交結果 | 首頁 > 服務項目 > `[服務名稱]` > 申辦 > 結果 |
| 公開內容頁 | 首頁 > `[頁面標題]` |

## 4. 入口與返回路徑

| 目標頁面 | 主要入口 | 返回路徑 | 備註 |
|---------|---------|---------|------|
| 服務列表 `/services` | Header 導航 / 首頁 CTA | ← 首頁 | — |
| 服務詳細 `/services/:id` | 列表卡片點擊 | ← 返回服務列表 | 麵包屑 |
| 申辦表單 `/apply/:serviceId` | 服務詳細頁「立即申辦」按鈕 | ← 返回服務詳細 / 取消 | 需驗證是否登入（Assumption） |
| 提交結果 | 表單成功送出後導向 | ← 返回首頁 / 重新申辦 | 防止重複送出 |
| 登入 `/login` | Header / 未授權重導向 | ← 返回上一頁 / 登入成功導向來源 | Assumption |
| 個人頁 `/account` | Header（登入後）| ← 返回首頁 | Assumption |
| 404 | 任何無效路由 | ← 返回首頁 | — |
| 403 | 未授權存取保護頁面 | ← 返回首頁 / 登入 | Assumption |
| 500 | 伺服器錯誤 | ← 重試 / 返回首頁 | — |

## 5. 角色權限矩陣

> **⚠ Assumption**：以下角色與權限為規劃假設，依據 SOW 2.0 使用者角色章節。是否需要登入、角色分級與管理後台待 P0 確認。

| 頁面 | 訪客（未登入） | 已登入使用者 | 業務管理者（C） | 備註 |
|------|:---:|:---:|:---:|------|
| 首頁 `/` | ✅ | ✅ | ✅ | — |
| 服務列表 `/services` | ✅ | ✅ | ✅ | — |
| 服務詳細 `/services/:id` | ✅ | ✅ | ✅ | — |
| 公開內容頁 `/info/:slug` | ✅ | ✅ | ✅ | — |
| 登入 `/login` | ✅ | ↩ 重導向 | ↩ 重導向 | 已登入者重導向 |
| 申辦表單 `/apply/:serviceId` | ❓ 待確認 | ✅ | ✅ | 是否需登入待 P0 確認 |
| 提交結果 | ❓ 待確認 | ✅ | ✅ | — |
| 個人頁 `/account` | ❌ 重導向登入 | ✅ | ✅ | Assumption |
| 管理後台 | ❌ | ❌ | ✅（C） | 是否納入待 P0 確認 |
| 404 / 403 / 500 | ✅ | ✅ | ✅ | 系統頁面 |

**圖例**：
- ✅ = 可存取
- ❌ = 無存取權，重導向或顯示 403
- ↩ = 已有對應狀態，自動重導向
- ❓ = 待 P0 確認
- C = 條件式，需求方核准後才納入

## 6. 系統頁面規劃

### 6.1 404 頁面未找到

**觸發時機**：使用者存取不存在的路由

**建議內容**：
- 清楚的標題「找不到頁面」（或同義文字）
- 簡短說明（不暴露系統細節）
- 返回首頁的 CTA 按鈕
- 可選：搜尋功能（待確認是否有搜尋功能）

### 6.2 403 無存取權限

**觸發時機**：使用者存取需要更高權限的頁面

**建議內容**：
- 清楚的標題「無存取權限」
- 簡短說明（不洩漏受保護資源的資訊）
- 登入 / 返回首頁的 CTA

### 6.3 500 伺服器錯誤

**觸發時機**：API 或系統發生預期外錯誤

**建議內容**：
- 清楚的標題「系統發生問題」
- 建議使用者重試或稍後再試
- 返回首頁的 CTA
- 不呈現技術錯誤細節給一般使用者
