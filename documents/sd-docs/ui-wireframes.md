## 2. 登入頁

**目的**：驗證使用者身份，取得 Session/Token  
**路由（假設）**：`/login`  
**狀態**：Assumption — 是否需要登入功能待 P0 確認  
**API 依賴**：`POST /api/login`（依 swagger.json）

### 2.1 桌面版 Wireframe

```
┌──────────────────────────────────────────────────────────────┐
│  HEADER                                                       │
└──────────────────────────────────────────────────────────────┘

              ┌──────────────────────────────┐
              │                              │
              │  [Logo / 品牌名稱（待確認）] │
              │                              │
              │  ────── 登入 ──────          │
              │                              │
              │  帳號 *                      │
              │  ┌──────────────────────┐    │
              │  │ 輸入帳號             │    │
              │  └──────────────────────┘    │
              │                              │
              │  密碼 *                      │
              │  ┌──────────────────────┐    │
              │  │ ••••••••          [👁]│   │
              │  └──────────────────────┘    │
              │                              │
              │  [錯誤訊息區（驗證失敗時）]   │
              │                              │
              │  ┌──────────────────────┐    │
              │  │      登 入（Loading）│    │
              │  └──────────────────────┘    │
              │                              │
              └──────────────────────────────┘

┌──────────────────────────────────────────────────────────────┐
│  FOOTER                                                       │
└──────────────────────────────────────────────────────────────┘
```

### 2.2 元件清單

| 元件 | 類型 | 說明 |
|------|------|------|
| Logo / 品牌名稱 | 靜態 | 待確認 |
| 帳號輸入框 | Input（type="text"） | 必填，aria-required |
| 密碼輸入框 | Input（type="password"） | 必填，顯示/隱藏切換 |
| 錯誤訊息 | Alert（role="alert"） | 登入失敗時顯示 |
| 登入按鈕 | Button（Primary） | 送出中顯示 Spinner，禁止重複點擊 |

### 2.3 狀態清單

| 狀態 | 描述 |
|------|------|
| Default | 空白表單，等待輸入 |
| Validation Error | 欄位空白或格式不符，顯示各欄位錯誤訊息 |
| Loading | 送出中，按鈕顯示 Spinner，禁止操作 |
| API Error | 帳號密碼錯誤，顯示行內錯誤訊息 |
| Locked | 失敗次數過多，帳號鎖定提示 |
| Success | 登入成功，導向來源頁面或首頁 |

### 2.4 操作流程

```
使用者輸入帳號/密碼
    → 點擊「登入」
    → 前端驗證（空白、格式）
        ├── 失敗 → 顯示欄位錯誤訊息，focus 移至第一個錯誤欄位
        └── 通過 → POST /api/login
            ├── 成功 → 儲存 Token/Session → 導向目標頁面
            ├── 401 帳密錯誤 → 顯示錯誤訊息
            ├── 429 鎖定 → 顯示鎖定訊息
            └── 500 系統錯誤 → 顯示系統錯誤訊息
```

### 7.2 狀態清單

### 7.3 操作流程

```
使用者填寫表單

        └── 通過 → POST API
            ├── 成功 → 導向結果頁（/apply/:id/result）
            ├── 400 驗證錯誤 → 顯示欄位錯誤
            ├── 401 未授權 → 導向登入（Assumption）
            └── 500 系統錯誤 → 顯示錯誤訊息
```
