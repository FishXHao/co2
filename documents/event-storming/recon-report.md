## 1. 網站定位

一個**公開資訊網站**，由台灣中油建置，介紹鐵砧山碳封存（CCS）計畫，提供計畫背景、環境監測資料與國際案例等資訊。無登入、無個人化服務。

## 3. 技術特徵與非功能需求

- **響應式**：支援手機、平板與桌面。
- **無障礙（Accesskey）**：網站分四大區塊（上方主選單、快速導覽、主內容、下方選單），快捷鍵 `Alt+0`~`Alt+4`。
- **動態圖表**：4 個環境監測頁以大氣/地下水/地震/土壤氣體圖表呈現動態資料，需 JS 渲染。
- **表單/輸入**：無（純資訊展示）。
- **多語系**：中文（zh-Hant-TW）。
- **內容授權**：內容屬台灣中油與環輿科技，正式上線需取得授權。

## 4. 開發範圍建議（功能對等）

- 實作上述 10 個路由，以 Vue 3 + Vite 建立響應式、無障礙網站。
- 環境監測圖表：**MVP 以固定 mock 資料在前端展示，後端 API 之後再串接**。
- 無登入、無後台、無第三方整合。
- 遵循 Accesskey 快捷鍵與 WCAG 無障礙目標。
